# AKUAPEMCONNECT MODERATOR PERFORMANCE & REWARDS MODULE

Build a Moderator Performance & Rewards Module that tracks moderator activities, measures productivity, and calculates earnings or rewards based on work completed.

The module must integrate with:

* News Module
* Events Module
* Funeral Module
* Marketplace Module
* Delivery Module
* Jobs Module
* Advertisements Module
* User Management

---

# PERFORMANCE POINT SYSTEM

Assign points for each completed task.

Example:

Approve Product = 2 Points

Reject Product = 2 Points

Approve Event = 2 Points

Approve Funeral Announcement = 2 Points

Approve Delivery Request = 1 Point

Resolve User Report = 5 Points

Resolve Dispute = 10 Points

Verify Seller = 5 Points

Verify Rider = 5 Points

Suspend Fraudulent User = 8 Points

Admin can modify point values.
