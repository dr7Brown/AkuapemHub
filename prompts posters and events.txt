# FUNERAL ANNOUNCEMENTS MODULE

## Purpose

Allow funeral announcements and memorial information to be published for community members.

## Public Features

Allow visitors to:

* Browse funeral announcements
* Search announcements
* View full funeral details
* View funeral posters
* Share announcements

No login required.
Login users can Create or post, and edit their funeral announcements, for a fee. 

## Admin Features

Allow administrators to:

* Can also Create announcements
* Edit announcements
* Delete announcements
* Approve submissions
* Reject submissions
* Feature announcements
admin to approve
Admin to set the fee on his dashboard. Admin to make it free or paid
when paid, admin manages it all.

## Funeral Fields

* Deceased Name
* Gender
* Age
* Photograph
* Funeral Poster
* Date of Birth
* Date of Death
* Biography
* Wake Keeping Date
* Burial Date
* Thanksgiving Service Date
* Venue
* GPS Address
* Organizer Name
* Organizer Phone
* Organizer Email
* Status
* Featured
* View Count

## Funeral Listing

Display:

* Photo
* Name
* Age
* Burial Date
* Location
* View Details button

Display featured funeral announcements at the top.

# EVENTS MODULE

## Purpose

Provide a platform for promoting community events, conferences, church programs, festivals, weddings, educational programs, and business events.

## Public Features

Allow visitors to:

* Browse events
* Search events
* View event details
* Share events

No login required.

## Admin Features

Allow administrators to:

* Create events
* Edit events
* Delete events
* Publish events
* Cancel events
* Feature events

## Event Fields

* Event Title
* Featured Image
* Description
* Venue
* GPS Address
* Start Date
* End Date
* Start Time
* End Time
* Organizer Name
* Ticket Type
* Ticket Price
* Registration Link
* Status
* Featured
* View Count

## Event Listing

Display:

* Event image
* Event title
* Event date
* Venue
* Event status
* View Details button

Upcoming events should appear before past events.
