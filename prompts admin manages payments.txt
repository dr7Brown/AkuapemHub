You are a senior full-stack web developer. Build a Job Posting and Payment System for a platform called AkuapemHub.
The system allows users to post jobs and choose between two payment modes:
Escrow Payment (platform holds money)
Direct Payment (client pays worker directly)
The system must be production-ready, secure, and scalable.

🧩 CORE REQUIREMENT

When a user posts a job, they must choose a payment method:

Escrow Payment (Recommended / Secure)
Direct Payment (Off-platform / Risky)
🔵 ESCROW PAYMENT MODE (IMPORTANT)

If escrow is selected:

Flow:
Client posts job and sets budget
System calculates commission
Client pays full amount upfront into AkuapemHub system
Funds are held in escrow (not released to worker yet)
Workers apply for job
After job completion:
Client approves release OR
Admin can releases after a set number of days if worker says work is done but job owner does not approve

Worker receives payment minus commission
Rules:
Money must be locked in escrow after payment
No withdrawal until job is marked completed
Admin can override disputes
System must track full transaction lifecycle
🟡 DIRECT PAYMENT MODE

If direct payment is selected:

Flow:
Client posts job
Worker is matched
Worker completes job
Client pays worker directly (MTN MoMo, cash, etc.)
AkuapemHub does NOT hold money
Rules:
No escrow involvement
System only tracks job completion
Show warning: “AkuapemHub is not responsible for payments in direct mode”
