# AKUAPEMCONNECT MARKETPLACE SUBSCRIPTION & LISTING PACKAGE MODULE

Build a complete Marketplace Subscription Package Module that allows shop owners to subscribe to different marketplace plans before they can list products.

The module must support package creation, listing limits, recurring subscriptions, renewals, expiry management, notifications, analytics, and unlimited plans.

The system must integrate with:

- Marketplace
- Shops
- Products
- Payments
- Wallet
- Notifications
- Admin Dashboard
- Analytics
- Audit Logs

--------------------------------------------------
BUSINESS OBJECTIVE
--------------------------------------------------

Every shop must subscribe to a Marketplace Package.

Each package determines:

• Maximum products allowed
• Subscription duration
• Featured benefits
• Price
• Renewal period
• Available features

No shop can publish products without an active subscription.

--------------------------------------------------
UPGRADE PACKAGE
--------------------------------------------------

Seller may upgrade anytime.

Upgrade activates immediately.

Admin may choose:

Prorated billing

OR

Charge full amount

Configuration controlled by admin.

--------------------------------------------------
DOWNGRADE PACKAGE
--------------------------------------------------

Downgrade takes effect after current subscription expires.

If the seller currently exceeds the new package limit:

Existing products remain visible.

No new products can be added until the number of active products is below the new package limit.

Never automatically delete products.

--------------------------------------------------
BUSINESS OBJECTIVE
--------------------------------------------------

Create a flexible subscription-based marketplace that generates recurring revenue while giving sellers package options based on the size of their business. The system must support small businesses, growing businesses, and enterprise sellers through configurable product limits and an Unlimited package without requiring future code changes. One additional recommendation

Instead of limiting sellers by "products per month", limit them by "active product listings".

For example:

Starter: Up to 10 active listings at any time.
Business: Up to 75 active listings.
Unlimited: Unlimited active listings.

If a seller sells an item or archives a listing, that slot becomes available again. This is fairer for sellers and encourages them to keep their inventory fresh without feeling penalized for being active on the platform.
